💸 PocketPilot

Smart Budget Management for Students

Developed by Team Veyron Vault!

📌 About the Project

PocketPilot is a student-focused budget management web application that helps students track daily expenses, manage food budgets, split shared expenses, and visualize spending using charts.

🎯 Problem Statement

Students often struggle to manage their limited budgets, track daily spending, and divide expenses with friends.

💡 Our Solution

PocketPilot provides a simple platform to track expenses, manage budgets, and understand spending habits.

✨ Key Features

- Daily Expense Tracking
- Food Budget Management
- Shared Expense Splitting
- Spending Visualization using Charts
- Budget Monitoring
